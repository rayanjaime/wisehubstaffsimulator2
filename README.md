# Homeaglow Hubstaff + Wise Training Simulator

Practice flow: Payment accounts > Edit (pencil) on the Wise account > type the Wise Tag Name > choose PHP – Philippine Peso > Save.

## Run locally
1. `npm install`
2. `npm run dev` and open http://localhost:3000

## Deploy
1. Upload this folder to a GitHub repository (do not upload `node_modules`).
2. In Vercel choose **Add New > Project**, import the repository.
3. Vercel detects Vite. Build command `npm run build`, output directory `dist`. Click **Deploy**.
